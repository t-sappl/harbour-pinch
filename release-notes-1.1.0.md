## Pinch 1.1.0

- Equalizer: presets (Balanced, Voice, Treble, Bass) and a custom preset with
  bass/mid/treble sliders, on a new "Equalizer" page
- Streamlined main page: the rarely used ear tip fit test, find my earbuds
  and device info now live on a "More" page instead of crowding the main
  screen
- Battery row: the case column now only appears while the case actually
  reports a level (buds docked, case open), like Nothing X; otherwise two
  wider columns for left/right instead of a dash
- Fixed a stale "earbuds not reachable" message sometimes still showing
  after the earbuds had actually reconnected

Developed by Thomas Sappl together with Claude (Anthropic) – analysis, design, code, reviews and tests.
